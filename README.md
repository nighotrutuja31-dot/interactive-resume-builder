# Interactive Resume Builder

## VEDA Technology - Task 29

An interactive resume builder developed using HTML5, CSS3 and JavaScript.

## Features

- Personal information form
- Education section
- Experience section
- Skills section
- Live resume preview
- Dynamic education entries
- Dynamic experience entries
- Add/remove functionality
- Responsive design
- Print-friendly resume
- Save resume as PDF
- Real-time form data binding

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter resume information.
5. Preview the resume in real time.
6. Click Print / Save PDF to export the resume.
